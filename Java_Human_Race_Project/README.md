# 🏃 Java Human Race Game

A colorful 2D racing game created using **Java Swing**.

## Features
- 🏃 Human runner character
- 🛣️ Race track and finish flag
- 🚧 Obstacles
- 🦘 Jump using SPACE
- 🏆 Score system
- ⚡ Increasing game speed
- 🔄 Restart using R
- 🎨 Colorful graphics

## Run

```bash
javac Main.java
java Main
```

## Controls

- **SPACE** → Jump
- **R** → Restart after Game Over

Created as a Computer Graphics learning project using Java.
